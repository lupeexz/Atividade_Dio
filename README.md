# Atividade_Dio

# Simulador de Investimentos em FIIs

## Sobre o projeto

Esse projeto foi desenvolvido como parte de um laboratório de Excel, com a ideia de colocar em prática os conhecimentos aprendidos durante as aulas.

A proposta foi criar uma planilha que simulasse investimentos em Fundos Imobiliários (FIIs), permitindo visualizar como um investimento pode evoluir ao longo do tempo.

A ideia é bem simples: o usuário informa alguns dados, como o valor que pretende investir, o tempo de investimento e a rentabilidade esperada, e a planilha faz os cálculos automaticamente.

## O que a planilha calcula

A partir dos dados informados, a ferramenta apresenta algumas informações importantes, como:

* Valor total investido;
* Patrimônio acumulado;
* Rendimento ao longo do tempo;
* Estimativa de dividendos mensais;
* Evolução do investimento.

Também é possível alterar os valores utilizados na simulação e observar como isso afeta o resultado. Assim, dá para testar diferentes cenários de investimento de uma forma rápida e fácil.

## Objetivo

O principal objetivo foi transformar os conceitos de Excel em uma ferramenta que tivesse uma aplicação prática. Além de praticar fórmulas e organização de dados, a planilha ajuda a visualizar melhor como diferentes valores e períodos de investimento podem influenciar o resultado.

Vale lembrar que os valores apresentados são apenas simulações e não representam garantia de rentabilidade dos investimentos.
